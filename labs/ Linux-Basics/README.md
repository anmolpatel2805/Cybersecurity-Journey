# Objective

The objective of this room was to build a strong foundation in Linux by learning essential terminal commands, file system navigation, permissions, file management, and basic shell operations commonly used in cybersecurity.

- Linux File System
- Terminal Navigation
- Files and Directories
- Absolute vs Relative Paths

- File Permissions
- Users and Groups
- File Ownership
- Searching for Files
- Text Manipulation
- Package Management

# Commands Practiced

## Navigation

```bash
pwd
ls
ls -la
cd
```

## File Management

```bash
mkdir
touch
cp
mv
rm
rmdir
```

## Viewing File Contents

```bash
cat
less
head
tail
```

## Searching

```bash
find
grep
```

## Permissions

```bash
chmod
chown
```

## User Information

```bash
whoami
id
hostname
```

## System Information

```bash
uname -a
history
clear
```

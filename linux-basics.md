#Linux filesystem basics
Important directories:
- /home : stores userfiles
- /bin : contains essential system commands
- /etc : configuration files
- /tmp : temporary files
## Basic linux commands
pwd --> prints the current working directory
ls --> lists files and directories in the current folder
cd --> change the current directory
mkdir --> creates a new directory
touch --> creates a new empty file. If the file already exists it updates timestamp
cp --> copies file from one location to another
mv --> moves or renames files
rm --> delete files or directories
rmdir --> deletes an empty directory
##Conclusion
These commands help users navigate and manage files in the linux OS.They are fundamental for cybersecurity proffessionalssince most security tools operate on linux systems.

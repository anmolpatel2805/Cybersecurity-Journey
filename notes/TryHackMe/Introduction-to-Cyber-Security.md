# TryHackMe – Offensive Security Intro

## Room Overview
This room introduced the concept of Offensive Security and demonstrated how ethical hackers legally test systems to find vulnerabilities before malicious attackers do.

It included a small hands-on lab where I performed a basic web exploitation in a safe environment.

---

## What is Offensive Security?

Offensive Security is the practice of actively testing systems, networks, and applications to identify security weaknesses.

Instead of defending, offensive security professionals simulate real-world attacks to discover vulnerabilities.

This approach helps organizations fix security issues before attackers can exploit them.

---

## Key Roles in Offensive Security

- Penetration Tester
- Red Team Member
- Ethical Hacker
- Bug Bounty Hunter

These professionals legally hack systems with permission.

---

## What I Did in This Room

- Started a virtual lab environment
- Interacted with a vulnerable website
- Performed a simple web-based attack
- Successfully exploited the target in a controlled environment

This demonstrated how small vulnerabilities can be abused if not properly secured.

---

## Key Learning Points

- Offensive security is proactive.
- Ethical hacking must always be authorized.
- Even simple websites can contain vulnerabilities.
- Practical labs improve understanding more than theory alone.

---

## My Understanding

Offensive security focuses on thinking like an attacker in order to strengthen defense mechanisms. By simulating attacks, organizations can improve their security posture and reduce real-world risks.

This room helped me understand how ethical hacking works at a basic level and how controlled lab environments are used for safe practice.
# TryHackMe – Defensive Security Intro

## Room Overview

This room introduced Defensive Security and its importance in protecting systems, networks, and organizations from cyber attacks.

It covered key defensive domains such as SOC, Digital Forensics, Incident Response, Threat Intelligence, Malware Analysis, and SIEM.

---

## What is Defensive Security?

Defensive Security focuses on protecting systems by:

- Monitoring networks
- Detecting attacks
- Investigating incidents
- Responding to security breaches

Unlike offensive security, which simulates attacks, defensive security works to prevent and minimize damage from real-world threats.

---

## Key Areas Covered

### 1. Security Operations Center (SOC)
A SOC is a centralized team that continuously monitors an organization’s security.

SOC analysts:
- Monitor alerts
- Investigate suspicious activity
- Respond to potential threats

---

### 2. Digital Forensics (DFIR)

Digital Forensics involves collecting and analyzing digital evidence after a security incident.

It helps:
- Identify how an attack happened
- Determine what was affected
- Preserve evidence for legal or internal investigation

---

### 3. Incident Response

Incident Response focuses on managing and containing cyber attacks.

Typical steps include:
- Detection
- Containment
- Eradication
- Recovery
- Lessons learned

---

### 4. SIEM (Security Information and Event Management)

SIEM tools collect and analyze logs from multiple systems to detect suspicious behavior.

They help security teams:
- Correlate events
- Generate alerts
- Monitor real-time threats

---

## Practical Understanding

In this room, I explored how defensive teams:

- Detect attacks in real time
- Analyze suspicious logs
- Investigate security incidents
- Strengthen system defenses

It showed how important monitoring and response are in real-world security operations.

---

## Key Learning Points

- Defensive security is reactive and proactive.
- Continuous monitoring is essential.
- Logs and alerts are critical for detection.
- Incident response must be structured and organized.

---

## My Understanding

Defensive security focuses on protecting and monitoring systems to prevent damage from cyber attacks. It requires constant vigilance, analysis of logs, and coordinated response efforts.

This room helped me understand the structure of security operations and how organizations defend against real-world threats.
